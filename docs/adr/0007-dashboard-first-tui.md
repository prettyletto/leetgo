# Dashboard-First TUI

Leetgo's TUI opens to an action-first Dashboard after Onboarding, rather than the current Problem list. The Problem list remains available inside deeper Roadmap, Stage, and Problem browsing flows, but the default experience is centered on the user's Next Actions because the product is a guided practice companion rather than a catalog browser.

**Considered Options**: Keep the Problem list as the default, make the startup screen configurable, replace the default with Dashboard.
**Consequences**: The TUI model needs explicit navigation between Dashboard, Roadmap Detail, Stage Detail, and Problem Detail, and list behavior must move from the root model into a deeper view.

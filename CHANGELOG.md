# Changelog

## v0.1.0 - 2026-06-26

First public release.

### Added

- Dashboard-first Bubble Tea TUI.
- Curated DAG roadmap with prerequisite gates.
- Roadmap, stage, problem detail, solve log, onboarding, and completion screens.
- Responsive Problem Detail layout with context/progression cycling and scrolling.
- Roadmap grouping tabs for stages and solved Problems.
- Local workspace generation for multiple languages.
- Local TestSuite execution from the TUI and CLI.
- SQLite progress store with migrations.
- XP, levels, streaks, achievements, reward events, and review cycles.
- Browser-assisted LeetCode Session setup and submission flow.
- JSON export/import and Git export support.
